# Find The Fox — Level 3 素材包

本包依據 Level 3 v3 素材規格製作，主題為耳廓狐／沙漠星空／綠洲。包含 1 張全景背景、13 件 Tier B 狐形物件及 3 件 Tier C 局部線索。

## 交付內容

| 類別 | 數量 | 狀態 |
|---|---:|---|
| 全景背景 | 1 | 已生成，2560×1440 |
| Tier B 狐形物件 | 13 | 已生成，透明 PNG |
| Tier C 局部線索 | 3 | 已生成，透明 PNG |
| Tier A 狐狸角色 | 15 | 未包含；原文件指向未提供的 v2 prompt |

## 使用注意

背景中的人物、駱駝及 Saluki 只作裝飾，沒有獨立 hitbox。所有 ground_only 目標必須放在實際地面或物件承托面，且不可覆蓋人物或動物的面部。座標、hitbox、anchor_ref 需要在實際 compositing 後補入 manifest。

## 檔案規格

背景是寬幅 PNG；sprite 與線索是獨立透明 PNG。預覽中的棋盤格代表透明背景。
